# Recipe Gen

[English](#english) | [日本語](#日本語)

---

## English

Recipe Gen is a free, iPhone-first web app (PWA) that creates recipes using only ingredients you can buy at an ordinary Japanese supermarket. Recipes are generated by a free AI model on **Cloudflare Workers AI** via a small backend worker — no account, no API key, no model download on your phone.

### Features

- Generate recipes from the ingredients you have, a dish idea, or a mood
- Ingredients limited to what Japanese supermarkets actually stock
- AI generation via a free Cloudflare Worker (Workers AI); results are re-validated in the app
- Save, browse and delete recipes; stored locally in IndexedDB
- Saved recipes work offline (creating new recipes needs an internet connection)
- Japanese and English interface
- Installable to the iPhone Home Screen like a native app

### Requirements

- **Any iPhone with Safari** (or any modern browser) and an **internet connection** to create recipes.
- No model download and almost no storage needed.

### Install on iPhone

1. Open `https://<your-username>.github.io/recipe_gen/` in **Safari**.
2. Tap the **Share** button.
3. Tap **Add to Home Screen**, then **Add**.
4. Launch Recipe Gen from the Home Screen icon.

### Privacy

When you create a recipe, your request (prompt, selected ingredients, time/servings/budget) is sent to the app's Cloudflare Worker, which asks Cloudflare Workers AI to write the recipe. No account or personal information is required. Saved recipes are stored **only on your device** (IndexedDB) and are never uploaded.

### Local development

```bash
npm install
npm run dev     # start the dev server
npm test        # run unit tests
npm run build   # production build into dist/
```

Icons in `public/` are generated with `node scripts/make-icons.mjs` (no dependencies).

### Backend (Cloudflare Worker)

The AI runs on a small Cloudflare Worker in `api/` (free plan is enough).

1. Create a free [Cloudflare account](https://dash.cloudflare.com/sign-up).
2. Log in from this project: `npx wrangler login`
3. Deploy the worker: `npm run api:deploy`
4. Copy the printed URL (e.g. `https://recipe-gen-api.<your-subdomain>.workers.dev`) into `API_URL` in `src/config.ts` (or set `VITE_API_URL` at build time), then rebuild/redeploy the app.

The free Workers AI allowance is limited per day; when it is used up the app shows a message asking you to try again tomorrow.

### Deployment (GitHub Pages)

1. Create a **public** GitHub repository named **`recipe_gen`** (the app is built with base path `/recipe_gen/`).
2. Push this project to the `main` branch.
3. In the repository, go to **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` tests, builds and deploys on every push to `main` (or run it manually from the Actions tab).
5. The app is published at `https://<your-username>.github.io/recipe_gen/`.

### Limitations

- Recipes are stored only in the browser where you created them. Deleting Safari website data, or using a different browser/device, means they will not be there. Use **export / backup in Settings** to keep a copy.
- Creating recipes needs an internet connection, and the free daily AI quota can run out.
- AI-generated recipes can contain mistakes. Use common sense with cooking times, temperatures and allergens.

### Cost

Free. Hosting on GitHub Pages is free, and the backend uses Cloudflare's free Workers / Workers AI plan. No API fees or subscriptions.

## 日本語

Recipe Gen は、日本の一般的なスーパーで買える食材だけを使ったレシピを作る、iPhone 向けの無料 Web アプリ（PWA）です。レシピは小さなバックエンド（Cloudflare Worker）経由で、無料の **Cloudflare Workers AI** が生成します。アカウント・API キー・端末へのモデルのダウンロードは不要です。

### 機能

- 手持ちの食材、作りたい料理、気分からレシピを生成
- 日本のスーパーで実際に手に入る食材に限定
- 無料の Cloudflare Worker（Workers AI）で AI 生成。結果はアプリ側でも検証
- レシピの保存・一覧・削除（IndexedDB にローカル保存）
- 保存したレシピはオフラインでも閲覧可能（新しいレシピの作成にはインターネット接続が必要）
- 日本語・英語の表示切り替え
- ネイティブアプリのようにホーム画面に追加可能

### 動作環境

- **Safari が使える iPhone**（または最新のブラウザ）と、レシピ作成時の **インターネット接続**。
- モデルのダウンロードは不要で、ストレージもほとんど使いません。

### iPhone へのインストール

1. **Safari** で `https://<ユーザー名>.github.io/recipe_gen/` を開きます。
2. **共有** ボタンをタップします。
3. **ホーム画面に追加** → **追加** をタップします。
4. ホーム画面のアイコンから Recipe Gen を起動します。

### プライバシー

レシピを作るとき、入力内容（リクエスト・選んだ食材・時間/人数/予算）がアプリの Cloudflare Worker に送信され、Cloudflare Workers AI がレシピを作成します。アカウントや個人情報は不要です。保存したレシピは **端末内（IndexedDB）にのみ** 保存され、アップロードされることはありません。

### ローカル開発

```bash
npm install
npm run dev     # 開発サーバーを起動
npm test        # ユニットテストを実行
npm run build   # dist/ に本番ビルド
```

`public/` のアイコンは `node scripts/make-icons.mjs` で生成しています（依存パッケージ不要）。

### バックエンド（Cloudflare Worker）

AI は `api/` にある小さな Cloudflare Worker で動きます（無料プランで十分です）。

1. 無料の [Cloudflare アカウント](https://dash.cloudflare.com/sign-up) を作成します。
2. このプロジェクトでログインします: `npx wrangler login`
3. Worker をデプロイします: `npm run api:deploy`
4. 表示された URL（例: `https://recipe-gen-api.<サブドメイン>.workers.dev`）を `src/config.ts` の `API_URL` に設定し（またはビルド時に `VITE_API_URL` を指定）、アプリを再ビルド・再デプロイします。

Workers AI の無料枠には 1 日あたりの上限があります。上限に達すると、翌日に再度お試しいただくようアプリにメッセージが表示されます。

### デプロイ（GitHub Pages）

1. **`recipe_gen`** という名前の **公開（Public）** GitHub リポジトリを作成します（ベースパスが `/recipe_gen/` のため）。
2. このプロジェクトを `main` ブランチにプッシュします。
3. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
4. `.github/workflows/deploy.yml` により、`main` へのプッシュごとにテスト・ビルド・デプロイが行われます（Actions タブから手動実行も可能）。
5. `https://<ユーザー名>.github.io/recipe_gen/` で公開されます。

### 制限事項

- レシピは作成したブラウザ内にのみ保存されます。Safari の Web サイトデータを削除したり、別のブラウザ・端末を使うと表示されません。**設定画面のエクスポート / バックアップ** で控えを保存してください。
- レシピの作成にはインターネット接続が必要です。また、1 日の無料 AI 枠を使い切ると翌日まで作成できません。
- AI が生成したレシピには誤りが含まれることがあります。加熱時間・温度・アレルギー食材などはご自身で確認してください。

### 費用

無料です。GitHub Pages でのホスティングは無料で、バックエンドは Cloudflare の無料プラン（Workers / Workers AI）を使います。API 料金やサブスクリプションは一切かかりません。
