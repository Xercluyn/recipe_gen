# Recipe Gen

[English](#english) | [日本語](#日本語)

---

## English

Recipe Gen is a free, iPhone-first web app (PWA) that creates recipes using only ingredients you can buy at an ordinary Japanese supermarket. Recipes are generated by an AI language model that runs **entirely inside your browser** — no server, no account, no API key.

### Features

- Generate recipes from the ingredients you have, a dish idea, or a mood
- Ingredients limited to what Japanese supermarkets actually stock
- Runs on-device with WebGPU (WebLLM + Qwen3 models from Hugging Face)
- Save, browse and delete recipes; stored locally in IndexedDB
- Works offline once the app and model are cached
- Japanese and English interface
- Installable to the iPhone Home Screen like a native app

### Requirements

- **iPhone with iOS 26 or later, using Safari** (WebGPU is required). Recent desktop Chrome / Edge / Safari also work.
- A one-time model download on first use:
  - **Standard model: about 1 GB**
  - **Light model: about 400 MB** (faster, lower quality; good for older devices)
- **Use Wi-Fi** for the first download. The model is cached afterwards.
- Enough free storage for the model.

### Install on iPhone

1. Open `https://<your-username>.github.io/recipe_gen/` in **Safari**.
2. Tap the **Share** button.
3. Tap **Add to Home Screen**, then **Add**.
4. Launch Recipe Gen from the Home Screen icon.

### Privacy

Everything happens on your device. Your ingredients, prompts and recipes are never sent to any server. The only network traffic is downloading the app itself (GitHub Pages) and the model files (Hugging Face) the first time.

### Local development

```bash
npm install
npm run dev     # start the dev server
npm test        # run unit tests
npm run build   # production build into dist/
```

Icons in `public/` are generated with `node scripts/make-icons.mjs` (no dependencies).

### Deployment (GitHub Pages)

1. Create a **public** GitHub repository named **`recipe_gen`** (the app is built with base path `/recipe_gen/`).
2. Push this project to the `main` branch.
3. In the repository, go to **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` tests, builds and deploys on every push to `main` (or run it manually from the Actions tab).
5. The app is published at `https://<your-username>.github.io/recipe_gen/`.

### Limitations

- Recipes are stored only in the browser where you created them. Deleting Safari website data, or using a different browser/device, means they will not be there. Use **export / backup in Settings** to keep a copy.
- Generation speed depends on your device's GPU; older devices may be slow or unsupported.
- AI-generated recipes can contain mistakes. Use common sense with cooking times, temperatures and allergens.

### Cost

Free. Hosting on GitHub Pages is free, the model runs on your own device, and there are no API fees or subscriptions.

## 日本語

Recipe Gen は、日本の一般的なスーパーで買える食材だけを使ったレシピを作る、iPhone 向けの無料 Web アプリ（PWA）です。レシピは **ブラウザの中だけで動く** AI 言語モデルが生成します。サーバー・アカウント・API キーは一切不要です。

### 機能

- 手持ちの食材、作りたい料理、気分からレシピを生成
- 日本のスーパーで実際に手に入る食材に限定
- WebGPU を使って端末上で動作（WebLLM + Hugging Face の Qwen3 モデル）
- レシピの保存・一覧・削除（IndexedDB にローカル保存）
- アプリとモデルのキャッシュ後はオフラインでも利用可能
- 日本語・英語の表示切り替え
- ネイティブアプリのようにホーム画面に追加可能

### 動作環境

- **iOS 26 以降の iPhone と Safari**（WebGPU が必要です）。最新のパソコン版 Chrome / Edge / Safari でも動作します。
- 初回利用時にモデルをダウンロードします（1 回のみ）:
  - **標準モデル: 約 1 GB**
  - **軽量モデル: 約 400 MB**（高速・やや低品質。古い端末向け）
- 初回ダウンロードは **Wi-Fi 環境** で行ってください。以降はキャッシュされます。
- モデルを保存できる空き容量が必要です。

### iPhone へのインストール

1. **Safari** で `https://<ユーザー名>.github.io/recipe_gen/` を開きます。
2. **共有** ボタンをタップします。
3. **ホーム画面に追加** → **追加** をタップします。
4. ホーム画面のアイコンから Recipe Gen を起動します。

### プライバシー

すべての処理は端末内で行われます。食材・入力内容・レシピがサーバーに送信されることはありません。通信が発生するのは、アプリ本体（GitHub Pages）と初回のモデルファイル（Hugging Face）のダウンロードのみです。

### ローカル開発

```bash
npm install
npm run dev     # 開発サーバーを起動
npm test        # ユニットテストを実行
npm run build   # dist/ に本番ビルド
```

`public/` のアイコンは `node scripts/make-icons.mjs` で生成しています（依存パッケージ不要）。

### デプロイ（GitHub Pages）

1. **`recipe_gen`** という名前の **公開（Public）** GitHub リポジトリを作成します（ベースパスが `/recipe_gen/` のため）。
2. このプロジェクトを `main` ブランチにプッシュします。
3. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
4. `.github/workflows/deploy.yml` により、`main` へのプッシュごとにテスト・ビルド・デプロイが行われます（Actions タブから手動実行も可能）。
5. `https://<ユーザー名>.github.io/recipe_gen/` で公開されます。

### 制限事項

- レシピは作成したブラウザ内にのみ保存されます。Safari の Web サイトデータを削除したり、別のブラウザ・端末を使うと表示されません。**設定画面のエクスポート / バックアップ** で控えを保存してください。
- 生成速度は端末の GPU 性能に依存します。古い端末では遅い、または動作しない場合があります。
- AI が生成したレシピには誤りが含まれることがあります。加熱時間・温度・アレルギー食材などはご自身で確認してください。

### 費用

無料です。GitHub Pages でのホスティングは無料で、モデルは自分の端末上で動作し、API 料金やサブスクリプションは一切かかりません。
